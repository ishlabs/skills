# AGENTS.md

Guidance for AI coding agents working in this repository.

## Editing the `ish` skill

`skills/ish/` is generated from <https://github.com/ishlabs/ish-cli/blob/main/src/lib/skill-content.ts> and overwritten on every CLI release. Do not edit files under `skills/ish/` here — your changes will be lost.

Bug reports for the `ish` skill: <https://github.com/ishlabs/ish-cli/issues>.

## Editing everything else

Hand-authored files — `README.md`, `LICENSE`, `AGENTS.md`, `CONTRIBUTING.md`, `.claude-plugin/marketplace.json`, `.github/workflows/`, `.gitignore` — are fair game. Open a PR.
